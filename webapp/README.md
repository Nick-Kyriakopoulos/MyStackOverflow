# MyStackOverflow — Web App

The Next.js frontend for MyStackOverflow. It is one service inside a .NET Aspire
solution, not a standalone app.

## Running it

Normally you don't start this directly — `aspire run` from the repository root brings it
up along with the gateway, databases and Keycloak it depends on. See the root
[README](../README.md).

To run just the frontend against an already-running backend:

```powershell
npm install
npm run dev      # http://localhost:3000
```

It needs two things from the environment:

- `API_URL` pointing at the YARP gateway, e.g. `http://localhost:8001`. Aspire injects
  this; set it yourself when running outside Aspire. Every request goes through
  `src/lib/fetchClient.ts`, which throws on any call made without it.
- `.env.local` with the Keycloak client and Cloudinary credentials. Not in version
  control.

## Layout

- `src/app/` — App Router pages
- `src/components/` — shared UI, built on HeroUI v3
- `src/lib/actions/` — server actions, the only place that talks to the API
- `src/middleware.ts` — signed-out redirects for protected routes
- `src/auth.ts` — Auth.js v5 with Keycloak, including refresh token rotation

## Before committing

```powershell
npx tsc --noEmit
npx eslint src --max-warnings=0
```

The React Compiler is enabled, and it silently skips components it cannot memoize — so
treat a "Compilation Skipped" lint warning as a real defect rather than noise.

`AGENTS.md` in this directory is generated by tooling (`next dev` and the HeroUI CLI
both write into it). Project conventions live in the root `AGENTS.md` instead.
